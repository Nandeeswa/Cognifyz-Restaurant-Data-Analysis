# Cognifyz Restaurant Data Analysis

## Project Overview
This project analyzes restaurant data using Python to identify useful insights about restaurant ratings, cuisines, pricing, and other business trends.

## Objectives
- Analyze restaurant data and identify patterns.
- Explore restaurant ratings and customer preferences.
- Study pricing and online delivery trends.
- Create charts and visualizations to communicate findings.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Data visualization
- Jupyter Notebook / Python scripts

## Project Structure
- `code/` – Python analysis scripts
- `data/` – Dataset used for analysis
- `charts/` – Generated charts and visualizations
- `tables/` – Analysis results in table format
- `report/` – Project report

## Project Outcome
The project demonstrates data cleaning, exploratory data analysis, visualization, and interpretation of restaurant data.
